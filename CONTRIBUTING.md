# Welcome to Open-DiffLoco

Open-DiffLoco is a scientific research project on differentiable simulation for policy training in mobile robotics.
The framework emphasizes high-performance computation and modular support for robotic embodiments.
Supported embodiments include:
- [Unitree Go2](https://shop.unitree.com/products/unitree-go2)

## How to Start

The project originated from a dedicated MSc Computing Science Master Thesis by [Martin Opat](https://martin-opat.com/) at the University of Groningen.
The implementation highlights are summarized in [README.md](README.md), with detailed notes in [docs/](docs/).

## Guidelines
- Submitted code shall follow and fit the performance-driven architecture of the project.
- Submitted code shall be commented or documented.
- A submitted PR shall include a meaningful, adequately-detailed description, so that code reviewers can check the submission algorithmically, conceptually as well as for code correspondence.
- Code submissions require review and approval by a core team member.
- Please be aware and adhere to the limitations of the project's license. Do not include library references of whose license restrictions you are unsure of.

## Style guidelines

Use the following style references:

- Python: [PEP8](https://www.python.org/dev/peps/pep-0008/)
- C++: project-local style
